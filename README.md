# Geld-Abenteuer

Ein datensparsames Expo-Startprojekt für ein 3D-Geldlern-Abenteuer für Kinder.

## Start
npm install
npx expo start

## Hinweis
Die erste Version enthält ein spielbares 2D-Prototyp-Interface. Für echte 3D-Renderings wird im nächsten Commit die 3D-Engine inklusive getesteter Expo-Kompatibility ergänzt.
